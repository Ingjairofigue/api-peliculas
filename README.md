#  API REST de Películas - IU Digital de Antioquia

##  Descripción
API REST desarrollada con Node.js, Express y Sequelize para la gestión de películas y series. Incluye 5 módulos: Género, Director, Productora, Tipo y Media.

##  Tecnologías
- Node.js
- Express
- Sequelize
- MySQL
- Postman

##  Instalación
1. Clonar el repositorio
2. Ejecutar `npm install`
3. Configurar el archivo `.env` con los datos de MySQL
4. Ejecutar `npm run dev`
